Generate a valid JSON array—or a single JSON object—containing Figma command objects that the MCP Figma plugin can process. Return **only raw JSON**, without explanations, code fences, comments, or additional text. All command objects must strictly follow the schema and rules below so they can be executed without errors inside the Figma plugin.

### Command Object Schema

Each command object may include the following fields:

- **action** (string, optional): One of `"create"`, `"update"`, `"move"`, `"delete"`.  
  - If omitted, the plugin automatically treats the command as `"create"`.

- **id** (string, required for `"update"`, `"move"`, `"delete"`):  
  - The unique Figma node ID to modify, move, or delete.

- **type** (string, required for `"create"`):  
  - Valid types: `"rectangle"`, `"circle"`, `"ellipse"`, `"frame"`, `"line"`, `"polygon"`, `"star"`, `"text"`, `"image"`, `"vector"`, `"boolean"`, `"component"`, `"instance"`.

- **x** (number, optional): X-position of the node.

- **y** (number, optional): Y-position of the node.

- **width** (number, optional): Width of the node (for create / resize).

- **height** (number, optional): Height of the node (for create / resize).

- **name** (string, optional): Node name assigned after creation.

- **color** / **background** (string, optional):  
  - Hex color string in `"#RRGGBB"` format.  
  - Plugin converts this to RGB and applies it as a solid fill.

- **stroke** (string, optional):  
  - Stroke color as a hex string `"#RRGGBB"`.

- **cornerRadius** (number, optional): Corner radius for nodes that support it.

- **text** (string, optional): Text content for TEXT nodes.

- **fontFamily** (string, optional): Font family to load (e.g. `"Inter"`).  
  - Plugin loads `"Regular"` style automatically if not specified.

- **fontSize** (number, optional): Font size for TEXT nodes.

- **textAlign** (string, optional): One of `"LEFT"`, `"CENTER"`, `"RIGHT"`.

- **url** (string, optional, for `image` type):  
  - HTTP/HTTPS URL to load an image.  
  - Must include `width` and `height`.

- **props** (object, optional, for `"update"`):  
  - Key-value pairs to update on the target node.  
  - Example: `{ "color": "#FF0000", "text": "Hello" }`.

- Additional layout or supported Figma node properties may be included; the plugin will attempt to set any property if it exists on that node type.

### Rules & Constraints

1. **Hex colors must always use the `"#RRGGBB"` format** with no alpha values.  
2. **For `"update"`, `"move"`, and `"delete"` commands, `id` is required** and must be a valid existing Figma node ID.  
3. **For `"create"` commands**, `"type"` is required; other attributes (x, y, size, styling) are optional but recommended.  
4. **Text nodes** should include `"text"` and may optionally specify `"fontFamily"` and `"fontSize"`.  
5. **Image nodes** must include a reachable `"url"` as well as `"width"` and `"height"`.  
6. **Order matters**: The plugin executes commands sequentially in the order they appear in the JSON array.  
7. **Use only supported Figma types**—avoid unsupported node types.  
8. **All numeric fields must be actual numbers**, not strings.  
9. **Do not include commentary, markdown, explanations, or code fences.** Output **only JSON**.
